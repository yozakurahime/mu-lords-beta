# MU Lords - Open Alpha

Canal público de distribuição do MU Lords. Este repositório contém somente os
documentos JSON consumidos pelo launcher; cliente completo e patches ficam nos
assets das releases.

- Site: `https://www.mulords.net`
- Cliente: Windows x64
- Temporada: Season 6 Episode 3
- Progressão: hard, sem resets, nível máximo 1000

Baixe sempre a versão mais recente na seção **Releases**.
